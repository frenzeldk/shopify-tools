Bin Count Sheet

List the bins to count. Every SKU stored in those bins is read from the local inventory database and printed as a packing slip with its expected on-hand quantity and a blank column to write the counted figure in.

One pattern per line, or separated by commas/spaces. * matches anything (A1-*), ? one character (A1-0?), [1-12] a number range (A1-[01-12]) and [A-D] a letter range.

The CSV export covers the same lines the sheet shows below — SKU, barcode, product, amount, cost per item and the line total — so the toggle above and any corrected quantity are reflected in it.

⚠️ Replace the local inventory?

This fetches every variant from Shopify and overwrites the whole local inventory database. Quantities changed here are replaced by Shopify's figures and cannot be recovered.

[[ inventory.locally_modified ]] SKU(s) have been changed locally since the last fetch. Those changes will be lost.

[[ inventory.added_locally ]] product(s) were added by hand. Shopify has no record of them, so they will be deleted, not refreshed.

A count sheet is open on screen. Regenerate it after the fetch to see Shopify's quantities.

The fetch walks the whole catalogue and can take a few minutes. If you only need current bins, use “Update Bins from Shipmondo” instead — it changes nothing else.
